# unslop

AI-slop audit + redesign hub for all builtbysai projects. Every redesign lives in its own `<repo>-redesign` repository — the originals are never touched.

## Contents

- `findings.md` — per-repo slop-checker verdicts, flagged patterns, reasoning, score ranking
- `inventory.md` — repo inventory with live URLs
- `phase2-plan.md` — redesign workflow and order
- `queue.md` — overnight work queue and status
- `screenshots/before/` — original designs
- `screenshots/after/` — redesigns
- `decks/` — image-only `.pptx` presentation per completed redesign
- `reviews/` — per-repo bug/issue/improvement writeups
